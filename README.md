## 🚀 Featured projects

### 🤖 AI that people can trust

| Project | What it does | Stack |
| --- | --- | --- |
| ⚖️ **[Ain Copilot](https://github.com/shariar165/Legal-Aid)** | Multi-agent legal copilot for Bangladesh. Reads a contract (PDF, DOCX or phone photo, Bangla or English), flags compliance risks, and writes a memo where **every legal claim is checked against official statute text**. Local OCR + PII shield. | Python · FastAPI · RAG · EasyOCR · LLM council |
| 🥔 **[Crop Guardian](https://github.com/shariar165/Crop-Guardian)** · [live](https://crop-guardian-pink.vercel.app) | Bengali, mobile-first advisor for potato farmers fighting late blight: daily weather risk, leaf-photo diagnosis **that admits uncertainty**, area risk map, season savings ledger. | Next.js · TypeScript · Tailwind |
| ⚓ **[Anchor AI](https://github.com/shariar165/Project--Anchor)** · [live](https://project-anchor-ten.vercel.app) | Civic trust platform: campus complaints & notices, FIR drafting, verified lawyer directory, safety alerts, and a legal assistant on a 7-stage RAG pipeline. | React · FastAPI · PostgreSQL · Redis · ChromaDB |
| 🤰 **[Maya](https://github.com/shariar165/Project-Maya)** · [live](https://project-maya-seven.vercel.app) | Maternal health companion with an AI assistant grounded in a medical knowledge base. | React · FastAPI · PostgreSQL · ChromaDB · MCP |
