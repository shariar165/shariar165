### 🚀 Featured projects

| Project | What it does | Built with |
| --- | --- | --- |
| 🛰️ **[Signal Delay](https://github.com/shariar165/space-mission-design-game-)** · [play](https://shariar165.github.io/space-mission-design-game-/) | A deep-space mission game on real orbital physics and NASA data. Your orders reach the spacecraft late, at the speed of light, and real solar storms come from NASA DONKI. Real missions are validated against the same model as player designs. | TypeScript · React 19 · Vite · Vitest · Playwright · GitHub Actions |
| ⚖️ **[Ain Copilot](https://github.com/shariar165/Legal-Aid)** | A multi-agent legal copilot for Bangladesh. It reads a contract (PDF, DOCX or a phone photo, in Bangla or English), finds compliance risks, and writes a memo in which every legal claim is checked against official statute text. Includes local OCR and a PII shield. | Python · FastAPI · RAG · EasyOCR · LLM council |
| ☀️ **[Solar Swarm](https://github.com/shariar165/Solar-Swarm)** · [demo](https://shariar165.github.io/Solar-Swarm/) | Five spacecraft near the Sun–Earth L1 point that sample a solar storm (CME) before it reaches Earth. Built on real solar-wind data, with a live NOAA feed mode and an interactive animation. | Python · JavaScript · data modelling |
| 🥔 **[Crop Guardian](https://github.com/shariar165/Crop-Guardian)** · [live](https://crop-guardian-pink.vercel.app) | A Bengali, mobile-first advisor for potato farmers fighting late blight: daily weather risk, leaf-photo diagnosis that admits uncertainty, an area risk map and a season savings ledger. | Next.js · TypeScript · Tailwind CSS |
| ⚓ **[Anchor AI](https://github.com/shariar165/Project--Anchor)** · [live](https://project-anchor-ten.vercel.app) | A civic trust platform: campus complaints and notices, FIR drafting, a verified lawyer directory, safety alerts, and a legal assistant with a 7-stage RAG pipeline. | React · FastAPI · PostgreSQL · Redis · ChromaDB |
| 🤰 **[Maya](https://github.com/shariar165/Project-Maya)** · [live](https://project-maya-seven.vercel.app) | A maternal health companion with an AI assistant grounded in a medical knowledge base. | React · FastAPI · PostgreSQL · ChromaDB · MCP |
| 🗣️ **[LinguaVerse AI](https://github.com/shariar165/LinguaForge-AI)** | An English-learning platform with an AI tutor, pronunciation scoring, quizzes, streaks and XP. | Next.js · FastAPI · Supabase · Groq |
| 📝 **[Notes App](https://github.com/shariar165/notepad)** | Full-stack notes with JWT auth, an admin panel, server-side search, and an assistant that answers questions about your notes. | React · Express · MySQL · Docker |
